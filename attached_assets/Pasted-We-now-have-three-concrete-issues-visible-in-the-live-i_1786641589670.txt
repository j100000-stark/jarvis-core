==================================================

The live system reports:

ELEVENLABS ........ TESTING SYNTHESIS
ELEVENLABS ........ ERROR 402
TTS ............... QUOTA_OR_BILLING
VOICE ............. BROWSER_FALLBACK_ONLY

This means the ElevenLabs upstream is rejecting the request because of quota/billing.

First inspect the complete ElevenLabs integration and determine exactly why the request returns 402.

Capture and safely log the upstream response category/status without exposing API keys.

The system must distinguish:

ELEVENLABS ONLINE
ELEVENLABS QUOTA EXCEEDED
ELEVENLABS BILLING REQUIRED
ELEVENLABS AUTHENTICATION ERROR
ELEVENLABS NETWORK ERROR

TTS FALLBACK

TTS REQUESTING

TTS ENDED

TTS REQUESTING

TTS FALLBACK
